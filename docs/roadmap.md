# Roadmap

Este ciclo está limitado aos prompts 01–05 do documento de construção fornecido por Pedro Buture.

1. Bootstrap: workspace, identidade, documentação e build.
2. Regras do repositório.
3. Tokens Buture Glass Dark.
4. GlassSurface e modos Full / Reduced / Off.
5. Janela nativa: top bar, activity bar, sidebar, editor sólido, inspector opcional, painel inferior e status bar.

Após o prompt 05, aguardar instruções do proprietário. Os prompts 06–95 não estão autorizados neste ciclo. O shell visual não representa um editor de texto, terminal, filesystem explorer ou integração de ferramentas prontos.
